# Testing notes

Automated tests: `dotnet test --project tests/CaptionOverlay.Core.Tests` (181 tests; 160 without a model, via
`-- --filter-not-trait "Category=RequiresModel"` as in CI). Tests that need a Whisper model use the models installed in
`%LOCALAPPDATA%\CaptionOverlay\models` (or `CAPTIONOVERLAY_TEST_MODEL` / `CAPTIONOVERLAY_TEST_MODEL_<ID>`) and skip
themselves when they are absent. `CAPTIONOVERLAY_UPDATE_WER_BASELINE=1` writes the measured German WER to
`tests/fixtures/de/wer-baseline.json`.
Live API tests (`LiveApiTests`, trait `RequiresApiKey`) are opt-in because they cost money: set `CAPTIONOVERLAY_TEST_API=openai` (or `groq`); the key comes from `CAPTIONOVERLAY_TEST_API_KEY` or the key saved in the app, and `CAPTIONOVERLAY_TEST_API_MODEL` overrides the model. The CLI (`live --api openai`) also falls back to the saved key.

English fixtures in `tests/fixtures` are generated by `scripts/generate-fixtures.ps1` with Windows TTS, with exact
speech boundaries in `*.labels.json`. German fixtures in `tests/fixtures/de` are 8 FLEURS clips fetched by
`captionoverlay-cli fixtures fetch-de` (ADR-014); the composite the tests use is built in memory.

## M3 — Local transcription
- ✅ Tiny model transcribes the speech fixture verbatim on Vulkan (RTF 0.008) and CPU (RTF 0.022); runtime logged.
- ✅ Filter drops "Untertitel im Auftrag des ZDF …" and similar; silence fixture never reaches the transcriber.
- ✅ `captionoverlay-cli live --wav … --realtime` prints tentative/committed lines; SRT timestamps match the fixture.
- ✅ German FLEURS clips (`GermanWhisperTests`, Vulkan, RTX 4090): aggregate WER large-v3-turbo-german-q5_0 8.6 % (threshold 12 %), small-q5_1 12.5 % (threshold 40 %), base-q5_1 23.4 % and tiny-q5_1 36.7 % (logged only); RTF ≤ 0.03. Per-clip values in `tests/fixtures/de/wer-baseline.json`. Remaining mismatches are mostly compounds (`Next Gen` vs `nextgen`, `Ringerkollegen` vs `ringer kollegen`) and the Indian names in `de_de_0019`. `large-v3-turbo-q5_0` was not installed (row skipped).
- ✅ German composite end-to-end (48 kHz stereo through the real pipeline): one line per cue, the long clip force-cut into 2 lines, SRT starts within 0.5 s; WER 10.2 % (German fine-tune), 14.8 % (small).
- ✅ Silence: no model yields a committed caption. The German fine-tune says "Vielen Dank." on digital silence; now dropped by the inaudible-audio rule (ADR-015).
- ⏳ Real German news clip on a mid-range GPU: finals ≤ 1.5 s after sentence end.
